# React To-Do List App

A simple and efficient To-Do List app built with React. This app allows users to manage their tasks by adding, editing, and deleting items. Tasks are saved in the browser's `localStorage`, ensuring persistence across sessions.

## Features

- Add new tasks to the list.
- Edit existing tasks.
- Delete tasks as needed.
- Persistent data storage using `localStorage`.
